## Install Junubify on your phone

Junubify is a responsive Progressive Web App (PWA). After the latest deployment is live, open **https://junubify2.vercel.app** in your phone browser while online:

- **Android (Chrome):** open the browser menu and tap **Install app** or **Add to Home screen**.
- **iPhone/iPad (Safari):** tap **Share**, then **Add to Home Screen**.

The installed app opens in a standalone app window. The app shell can load offline after it has been visited once; streaming audio and Supabase account/catalog features still require an internet connection. No APK/IPA or native SDK package is generated by this PWA setup.
